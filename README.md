# NightRead

Современная Android-читалка электронных книг с тёмным стекломорфным интерфейсом, живым AGSL-фоном и аккуратной вёрсткой текста.

## Возможности

- **Поддержка форматов:** FB2, FB2.ZIP, FB3, EPUB, MOBI / AZW / AZW3, TXT.
- **Сохранение форматирования:** корректное отображение **жирного**, *курсива*, <u>подчёркнутого</u>, ~~зачёркнутого~~ текста, верхних/нижних индексов и цитат.
- **Точная вёрстка страниц:**
  - автоматическое выравнивание высоты страницы под целое количество строк при любом шрифте и размере;
  - каждая новая глава начинается с новой страницы, заголовки глав выделены жирным по центру;
  - перенос слов, выбор шрифтов (`EB Garamond`, `Literata`, `Lora`, `Merriweather`, `Roboto`, `JetBrains Mono`), настройка жирности, межстрочного интервала и тем чтения.
- **Живой фон:** единый плавный переливающийся AGSL-шейдер (`LiquidWaveBackgroundView`) на всех экранах приложения (с Canvas-фоллбэком для Android 12 и ниже) и поддержкой пользовательского фона из галереи.
- **Библиотека:** автоматическое и инкрементальное сканирование устройства, ручной импорт, режимы сетки и списка, фильтрация по форматам, поиск, сортировка, избранное, «Хочу прочитать», группировка по авторам и сериям.
- **Инструменты чтения:** оглавление, закладки, заметки, поиск по тексту книги, встроенный оффлайн-словарь, перелистывание кнопками громкости.
- **Облачная синхронизация:** интеграция с Яндекс Диском для синхронизации книг и прогресса чтения (включая фоновую авто-синхронизацию).

## Стек технологий

- **Язык:** Kotlin, JVM 17
- **UI:** Jetpack Compose, Material 3, Android Views, AGSL (`RuntimeShader`), Coil
- **Хранение данных:** Room (SQLite), SharedPreferences
- **Асинхронность:** Kotlin Coroutines & Flow, WorkManager
- **Сборка и CI/CD:** Gradle (Kotlin DSL), GitHub Actions

## Требования

- Android 7.0 (API 24) и выше *(для AGSL-шейдера фона — Android 13 / API 33+)*
- JDK 17

## Сборка

    ./gradlew assembleDebug

Готовый APK появится в `app/build/outputs/apk/debug/`.

Также в репозитории настроен workflow GitHub Actions (`.github/workflows/build.yml`), который автоматически собирает APK при каждом пуше в ветку `main`.
